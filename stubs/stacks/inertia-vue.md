# Stack playbook — Laravel + Inertia + Vue (shadcn-vue)

## Structure

```
app/                      # standard Laravel; services in app/Services, actions in app/Actions
resources/js/
  app.ts                  # Inertia app entry (shared file — Tariq only)
  pages/                  # Inertia pages, PascalCase, grouped per module (pages/invoices/Index.vue)
  components/             # project components, grouped per module
  components/ui/          # shadcn-vue components — generated by CLI, never hand-edited
  composables/            # useXxx() composables
  lib/utils.ts            # cn() helper
  types/                  # shared TS types; API contracts live here
routes/web.php            # shared file — Tariq only (or one route file per module)
```

## Wiring (once, after installer --setup)

1. `php artisan inertia:middleware` then register `HandleInertiaRequests` in `bootstrap/app.php`.
2. Root Blade view `resources/views/app.blade.php` with `@inertia` + `@vite`.
3. `vite.config.ts`: `@vitejs/plugin-vue` + `@tailwindcss/vite` + alias `@ -> resources/js`.
4. `resources/js/app.ts`: createInertiaApp with `resolvePageComponent`, Ziggy plugin.
5. `tsconfig.json` with `@/*` paths; `resources/css/app.css` with `@import "tailwindcss";`.
6. shadcn-vue init: `npx shadcn-vue@latest init` — then add components as needed:
   `npx shadcn-vue@latest add button input form dialog table sonner`.

## Conventions

- Pages receive data ONLY via Inertia props from controllers; type every page's props in
  `types/`. The backend task pins the props contract; frontend builds against it.
- Forms: `useForm` from `@inertiajs/vue3`; always render `form.errors.<field>` under inputs;
  disable submit while `form.processing`.
- UI: compose shadcn-vue components from `components/ui/`; add new ones via the CLI only.
  Icons: `lucide-vue-next`. Toasts: sonner.
- Lists always handle loading/empty states; destructive actions get a confirm dialog.
- Never fetch with axios for page data — Inertia visits/partial reloads (`router.reload`).
- Backend: controllers return `Inertia::render('module/Page', [...])`; use Eloquent
  API-style resources or dedicated array shapes for props; paginate server-side.

## Checks a frontend task must pass

`npm run build` (includes vue-tsc type check if configured) and any Pest feature test
asserting the page renders (`$response->assertInertia(...)`).
