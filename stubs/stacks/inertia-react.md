# Stack playbook — Laravel + Inertia + React (shadcn/ui)

## Structure

```
app/                      # standard Laravel; services in app/Services, actions in app/Actions
resources/js/
  app.tsx                 # Inertia app entry (shared file — Tariq only)
  pages/                  # Inertia pages, PascalCase, grouped per module (pages/invoices/Index.tsx)
  components/             # project components, grouped per module
  components/ui/          # shadcn/ui components — generated by CLI, never hand-edited
  hooks/                  # useXxx() hooks
  lib/utils.ts            # cn() helper
  types/                  # shared TS types; API contracts live here
routes/web.php            # shared file — Tariq only (or one route file per module)
```

## Wiring (once, after installer --setup)

1. `php artisan inertia:middleware` then register `HandleInertiaRequests` in `bootstrap/app.php`.
2. Root Blade view `resources/views/app.blade.php` with `@inertia` + `@vite`.
3. `vite.config.ts`: `@vitejs/plugin-react` + `@tailwindcss/vite` + alias `@ -> resources/js`.
4. `resources/js/app.tsx`: createInertiaApp with `resolvePageComponent`.
5. `tsconfig.json` with `@/*` paths; `resources/css/app.css` with `@import "tailwindcss";`.
6. shadcn init: `npx shadcn@latest init` — then add components as needed:
   `npx shadcn@latest add button input form dialog table sonner`.

## Conventions

- Pages receive data ONLY via Inertia props from controllers; type every page's props in
  `types/`. The backend task pins the props contract; frontend builds against it.
- Forms: `useForm` from `@inertiajs/react`; always render `errors.<field>` under inputs;
  disable submit while `processing`.
- UI: compose shadcn/ui components from `components/ui/`; add new ones via the CLI only.
  Icons: `lucide-react`. Toasts: sonner.
- Lists always handle loading/empty states; destructive actions get a confirm dialog.
- Never fetch with axios for page data — Inertia visits/partial reloads (`router.reload`).
- Components are function components; derive state where possible, no redundant useEffect.
- Backend: controllers return `Inertia::render('module/Page', [...])`; paginate server-side.

## Checks a frontend task must pass

`npm run build` (includes tsc type check if configured) and any Pest feature test
asserting the page renders (`$response->assertInertia(...)`).
